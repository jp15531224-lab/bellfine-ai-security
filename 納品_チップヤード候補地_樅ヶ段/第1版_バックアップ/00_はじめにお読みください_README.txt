■ インタラクティブHTMLの使い方
  1. 「インタラクティブ現場確認_一式.zip」を展開（または05フォルダをそのまま使用）。
  2. 「インタラクティブ現場確認.html」をダブルクリック → ブラウザ（Chrome/Edge/Safari）で開きます。
     サーバーの起動やインストールは不要です。
  3. 画面上部のタブで切替：
     ・図面と撮影位置 … 番号をタップ／クリックすると現場写真が開きます。扇形＝撮影方向。
                          「現況／A案／B案／C案」で施設配置イメージを重ねて表示。
     ・地図・航空写真 … 航空写真（保存版）はオフラインでも表示。
                          「地理院 写真／地図」「土砂災害区域」「洪水浸水想定」はインターネット接続が必要。
     ・写真一覧／パノラマ … 一覧から選ぶと図面上の位置へ移動。
     ・協議事項・メモ … 地点ごとのメモ・確認事項のメモを入力（自動保存）。
  4. 写真表示中：ホイール／ピンチで拡大、ドラッグで移動、◀▶で前後の写真、「図面で見る」で位置へ。
  5. メモの共有：「メモを保存」でJSONファイルを書き出し → 相手は「メモを読み込み」。
     「テキストで書き出し」で議事録の下書きになります。
     ※メモは端末のブラウザ内に保存されます。端末やブラウザを変えると引き継がれないため、会議後は必ず書き出してください。
  ・iPhone/iPad：ZIPを「ファイル」アプリで展開し、HTMLを開く（共有→Safariで開く等）。
    環境により写真が表示されない場合は、PCで開くか、社内のWebサーバー等に05フォルダを置いて開いてください。

■ 必ず理解しておいていただきたい前提（品質管理）
  ・写真15枚のEXIFに GPS・撮影日時・方位は記録されていませんでした（共有時に削除とみられる）。
    撮影位置・方向はすべて、交差点・脇道・住宅・水路・対面ヤード等の目印による「推定」（信頼度B）です。
    → iPhoneの元データ（位置情報付き）を共有いただければ、GPSで再配置（信頼度A）できます。
  ・図面は文字が逆さの状態で受領したため、180°回転して北を上に表示しています（方位記号なし＝推定）。
  ・土地境界・面積・地番と所有者の対応は確定していません（図面の読取値。登記簿で要確認）。
  ・施設配置案A/B/Cは「概念図」です。寸法・面積・勾配・費用は検討していません。
  ・ハザード情報は国土地理院「重ねるハザードマップ」の参考表示です。正式範囲は兵庫県・宍粟市で確認が必要。
  ・パノラマは自動合成のため継ぎ目に歪みがあり得ます。寸法判断には元写真を使用してください。
  ・現況写真の加工（現況を偽る修正）は一切していません。
