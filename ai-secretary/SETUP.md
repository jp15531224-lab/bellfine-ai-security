# 本人がやる設定（合計 約20分・1回だけ）

## ① Routineにコネクタを付ける（5分・必須）
claude.ai（PCブラウザ推奨）→ Claude Code → Routines（ルーティン）一覧 → 各Routineを開いて編集 → コネクタ（Connectors）に追加 → 保存。

| Routine | 追加するコネクタ |
|---|---|
| 録音→Obsidian整理（議事録・人物・案件） | Google Drive、Plaud |
| 予定承認→カレンダー登録（Todoist承認制） | Google Drive、Todoist、Google Calendar |

- 付け終わったら Claude に「Routineのコネクタ付けた」と伝えてください。1回ずつ手動実行して動作確認します。
- 旧「ボイスメモ予定自動登録（朝・夕）」は停止済み（削除していないので再開可能）。

## ② 予定の承認のしかた（日常操作）
- Todoist「確認待ち」に `【予定承認】10/15(木) 10:00 相手｜用件` が届きます（ラベル: 予定承認）。
- **完了にする ＝ 承認** → 次の実行（9:53/13:53/17:53/21:53）でGoogleカレンダーに登録（紫色・招待メールなし）。
- **削除する ＝ 却下**。
- 日時が違う場合は、削除して自分でカレンダーに入れてください（AIは承認タスクを書き換えません）。

## ③ Obsidian Sync（iPhone で見る・10分）
1. PC の Obsidian で Vault「淳平」を開く → 設定 → コアプラグイン → 「同期（Sync）」をオン。
2. 設定 → 同期 → Obsidian アカウントでログイン（Sync プランの購入が必要）→ 「リモート保管庫を作成」→ 接続。
3. iPhone の Obsidian → 「Obsidian Sync で保管庫をセットアップ」→ 同じリモート保管庫を選択。
4. コミュニティプラグイン「Dataview」を PC と iPhone の両方で有効化（人物・案件ノートの自動一覧に使用）。
5. `AI秘書/00_AI秘書ホーム.md` をブックマーク（スター）しておくと便利。

注意（正直なリスク）:
- この構成は「Google Drive（PC）」と「Obsidian Sync」の二重同期になります。Obsidian 公式は二重同期を推奨していません。AI は新規ファイルを作るだけで既存ノートを書き換えないため衝突は起きにくい設計ですが、**同じノートを PC と iPhone で同時に編集しない**でください。
- AI が作ったノートは「Drive → PC → Obsidian Sync → iPhone」の順に届くため、**PC が起動していないと iPhone に反映されません**。
- Google Drive for desktop は「ファイルをミラーリング」設定を推奨（「ストリーミング」だと Obsidian での読み込みが遅くなることがあります）。

## ④ ChatGPT から参照する（5分）
1. ChatGPT → 設定 → アプリ／コネクタ → Google Drive を接続（画面名はプランや時期で変わります）。
2. 設定 → データコントロール → 「すべての人のためにモデルを改善する」をオフ。
3. ChatGPT でプロジェクト「AI秘書」を作り、指示欄に下記を貼り付け:

```
私は複数事業の経営者です。過去の会議・商談・人物情報は Google Drive の「淳平/AI秘書」フォルダ
（議事録/ 人物/ 案件/ 会社/）に Markdown で保存されています。
質問には必ずこのフォルダの議事録を検索して答え、回答の末尾に根拠として
「録音日時」「議事録ファイル名」「出典ID（plaud:… / drive:…）」を列挙してください。
「（聞き取り要確認）」と書かれた人名・社名は事実として扱わず、その旨を明記してください。
事実と推測を分けて答えてください。
```

- 使い方例: 「○○さんと過去に何を話した？未完了の約束は？」「△△社の件、決まったことを時系列で」
- Claude（claude.ai／iPhoneアプリ）でも同じ質問ができます。Claude は Plaud の原文・Todoist・カレンダーも横断できます。

## ⑤ グラフビューの色分け（任意・1分）
Obsidian（PC）→ 左のグラフアイコン → 右上の歯車 → 「グループ」→「新しいグループ」を4回押し、検索欄にそれぞれ入力して色を選ぶ:
- `path:AI秘書/事業` （赤）… 事業ハブ
- `path:AI秘書/議事録` （青）… 議事録
- `path:AI秘書/会社 OR path:AI秘書/案件 OR path:AI秘書/人物` （緑）… 取引先・案件・人物
- `path:AI秘書/文字起こし` （灰）… 文字起こし全文
見やすくするなら「フィルター」の検索欄に `path:AI秘書` と入れると AI秘書 以外を隠せます。
