# AI秘書システム 設計書（外部脳 × Plaud × ボイスメモ × Obsidian × カレンダー × Todoist）

最終更新: 2026-10-09

## 1. 目的
録音するだけで、議事録・案件・人物・予定・ToDo が自動整理され、Claude / ChatGPT から過去情報を検索・活用できる状態にする。

## 2. 全体構成

```
[録音]                         [取り込み]                         [保存・整理]                       [参照]
Plaud ──────────(Plaudコネクタで直接取得)──┐
iPhoneボイスメモ → Whisper Memos → Make → Drive「ボイスメモ」┤
AINOTE → Drive「AINOTE自動保存」────────────┤
                                            ▼
                         Claude Routines（クラウドで定期実行・PCを起動しておく必要なし）
                          ① 録音→Obsidian整理 ──────→ Drive「淳平」Vault / AI秘書/ … Markdown
                          ② 外部脳→Todoist登録（既存）→ Todoist（重複チェック付き）
                          ③ 予定登録（既存・要修理）──→ Googleカレンダー（承認制にする案）
                          ④ 毎朝の行動計画（既存）／⑤ 週次未完了チェック（既存）
                                            ▼
                    Obsidian（PC／iPhone）・Claude（Drive/Plaud/Todoist/カレンダー接続）・ChatGPT（Drive接続）
```

## 3. Obsidian 構成（Vault「淳平」/AI秘書/）
| フォルダ | 中身 | 作られ方 |
|---|---|---|
| 議事録/ | 録音1件=1ファイル。`YYYY-MM-DD_HHMM_題__plaud-xxxxxxxx.md` | 毎回新規作成（出典IDで重複防止） |
| 人物/ 会社/ 案件/ | 索引ノート（初出時に1回だけ作成） | 以後は議事録からのリンクで自動集約 |
| 処理ログ/ | 実行ごとの取り込み・スキップ・保留の記録 | 毎回新規作成 |
| _システム/ | `render_notes.py`（Routineがダウンロードして使用） | 手動更新 |

| 文字起こし/ | 外部脳（iCloud外部脳）の txt を Markdown にコピーしたもの。サブフォルダ ボイスメモ/ AINOTE/ ToDo予定候補/。`YYYY-MM-DD_HHMM_題__drive-xxxxxxxx.md` | 2026-10-09 に既存71件を一括取り込み（9件は無音・空・重複で除外）。以後は Routine §7b が新規分を自動コピー |

### 文字起こし取り込み（2026-10-09）
- 元ファイルは変更していない（Drive の copy_file で新規コピー。サイズ一致を全件確認）。取り込み前のバックアップ: マイドライブ直下「Obsidianバックアップ_淳平_20261009-取込前」（設定6ファイル＋保管庫ファイル一覧）。
- 索引: `文字起こし/00_文字起こし索引（日付別）.md`・`01_文字起こし索引（事業別）.md`（取引先・議事録・会社ノートへのリンク付き、事業分類はAI推定）、`文字起こし一覧.base`（新規分も自動表示）。
- 索引ノートは静的（自動更新しない）。新規分は `.base` と Obsidian 検索で見る。
- PLAUD は従来どおり Plaud コネクタ→議事録で自動化済み。Plaud の全文はPlaudアプリ側に残る（Driveにtxtは無い）。

各議事録の frontmatter に `recorded_at`（録音日時JST）、`source`（情報源）、`source_id`（原本ID）、`source_file`（元ファイル名）、`basis`（文字起こし確認済/要約のみ）、`business`、`people/companies/cases`（リンク）を記録。本文に 要約／関係者／案件／決定事項／約束／ToDo／確認待ち／予定（✅確定・❓要確認）／要確認／原本 を出力。

**なぜ「追記」でなく「新規ファイル＋リンク」か**: Drive コネクタは既存ファイルの中身を書き換えられない。これを逆手に取り「既存データを変更しない」を仕組みで保証し、人物・案件ノートへの情報集約は Obsidian のバックリンク／Dataview に任せる。人が手で書いたメモが AI に上書きされる事故も起きない。

## 4. 誤認識・重複・漏えい対策
| リスク | 対策 |
|---|---|
| 人名・社名の誤認識 | 要約と文字起こしで一致・複数回出現した時のみ `certain=true`。それ以外はリンク化せず「（聞き取り要確認）」表記。人物ノートは作らない |
| 本人の取り違え | 話者が本人と確信できない ToDo は「担当者要確認」 |
| 日付の誤り | 相対表現は録音日時基準でのみ絶対日付化。曜日矛盾は不記載。`validate` が `YYYY-MM-DD` 以外を拒否 |
| 予定の誤登録 | `確定` は「日付・開始時刻が1つ、合意あり、文字起こしで確認、引用(evidence)あり」のみ。要約のみの録音から `確定` は validate が拒否 |
| 重複 | 議事録ファイル名に出典ID、作成前にタイトル検索、索引ノートは存在すればスキップ。Todoist は既存の出典ID検索＋キーワード検索 |
| 既存データ破壊 | 新規作成のみ。変更・移動・削除は禁止（プロンプト＋コネクタ仕様の二重） |
| 個人情報漏えい | 電話番号・メール・口座番号・12桁番号を自動マスク。借金・人事・健康・家族等は `sensitivity: 機密` で概要のみ。実データはGitHubに置かない（本リポジトリはサンプルのみ） |
| プロンプトインジェクション | 録音内容は「データ」扱いと明記。Obsidian整理ジョブはカレンダー/Todoistに書かない |

## 5. カレンダー登録（Todoist承認制・採用）

> 2026-10-09 変更: 専用Routineにコネクタが付与できなかったため停止し、承認処理は既存の「毎朝の行動計画」（6:52、Drive/Todoist/Calendar 接続済み）に組み込んだ。承認した予定のカレンダー登録は翌朝。変更前の朝のプロンプトは `prompts/morning_plan_original_20261009.md`。
**採用: Todoist承認方式**（Routine `<RoutineID>`、ラベル「予定承認」作成済み）
1. 録音から `✅確定` の予定 → Todoist「確認待ち」に `【予定承認】10/15(木)10:00 山田建設 現地調査`（ラベル `予定承認`、説明に根拠の発言・出典ID）
2. 本人が iPhone の Todoist で **完了にする＝承認**／**削除する＝却下**
3. 次回実行で、完了済みの承認タスクだけカレンダー登録（4カレンダーで同日±60分の重複確認、`自動登録キー` 検索、colorId=5、招待メール無し）
4. `❓要確認` の予定はカレンダーにもTodoistにも入れず、議事録・行動計画の「予定候補」に表示

旧方式（確定は自動登録）の Routine は停止して保持。旧方式で登録済みの予定も同じ「自動登録キー」書式なので、新方式の重複チェックで検出される。

## 6. Claude / ChatGPT からの参照
- **Claude**: claude.ai / iPhoneのClaudeアプリで Google Drive・Plaud・Todoist・Googleカレンダーのコネクタが使える。「○○さんの件どうなってる？」→ 運用ルール§12の人物カルテ手順で、議事録ノート＋Plaud原文＋Todoistを横断。
- **ChatGPT**: ChatGPT の Google Drive 連携（設定 > コネクタ/アプリ）で Drive を接続すれば、`AI秘書/議事録` の Markdown を検索・引用できる（読み取り専用でよい）。Markdown は frontmatter に日時・出典を持つので、回答に原本IDを出させられる。
  - 注意: 接続すると ChatGPT 側から Drive 全体が見える。「データ管理 > モデル改善」をオフにすること。機密ノートは概要のみの設計にしてある。
- 共通: どちらも「回答には出典ID（plaud:… / drive:…）と録音日時を必ず付けて」と指示すると、原本に戻れる。
