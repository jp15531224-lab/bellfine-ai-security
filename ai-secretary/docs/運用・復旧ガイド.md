## 2. 取り込み元と行き先
| 録音 | 経路 | Obsidianでの置き場所 |
|---|---|---|
| iPhoneボイスメモ（Whisper Memos） | Whisper Memos → Make → Drive「iCloud外部脳/ボイスメモ」 | 文字起こし/ボイスメモ、議事録 |
| AINOTE | Drive「iCloud外部脳/AINOTE自動保存」 | 文字起こし/AINOTE、議事録 |
| PLAUD | Plaud コネクタで直接取得 | 文字起こし/PLAUD（AI要約）、議事録 |
| ToDo・予定候補 | Drive「ToDo一覧」「予定候補_確認待ち」 | 文字起こし/ToDo予定候補 |

## 3. 安全の仕組み
- **新規作成のみ**：AIは既存ノートを書き換えない・消さない（Driveの仕組み上もできない設定）。元の録音・文字起こしも読むだけ。
- **重複防止**：ファイル名の末尾に出典ID（`__plaud-xxxxxxxx` 等）。同じIDがあれば作らない。
- **誤認識対策**：はっきり聞き取れない人名・会社名はリンクにせず「（聞き取り要確認）」と書く。
- **機密**：借金・人事・健康・家族などは「🔒機密」で概要のみ。電話番号・メール・口座番号は自動で伏せ字。
- **ログ**：毎回「処理ログ_日時.md」。失敗時は「処理ログ_日時_エラー.md」に原因と未処理分を記録。

## 4. 困ったとき
| 症状 | 確認すること | 対処 |
|---|---|---|
| 新しい議事録が増えない | 処理ログフォルダの最新ファイルの日時 | エラーログがあれば内容を Claude に貼る。「接続エラー」なら claude.ai のルーティン画面でコネクタ（Google Drive・Plaud）を付け直す |
| ボイスメモが取り込まれない | Drive「iCloud外部脳/ボイスメモ」に新しい txt があるか | 無ければ Make のシナリオ／Whisper Memos の連携を確認 |
| 間違った議事録ができた | 該当ノート | そのノートを手で直すか削除してよい（AIは再作成しない。再作成させたい時はファイルごと削除） |
| 自動処理を止めたい | claude.ai → ルーティン | 「録音→Obsidian整理」をオフにする（いつでも再開可） |

## 5. バックアップと復元
- AIが作るのは新しいファイルだけなので、**不要になったらAIが作ったファイルを消せば元に戻る**。
- 設定変更前のバックアップ（マイドライブ直下）:
  - Obsidianバックアップ_淳平_20261008-1400（最初の設定前）
  - Obsidianバックアップ_淳平_20261009-取込前（文字起こし取り込み前）
  - Obsidianバックアップ_淳平_20261009-拡張前（事業・月別ハブ追加前）
- Google Drive の各ファイルは「版の履歴」から過去の状態に戻せる（右クリック → ファイル情報 → 版を管理）。

## 6. グラフビューの色分け（本人の操作・1回だけ）
1. Obsidian で左端の「グラフビューを開く」（●─● のアイコン、または Ctrl+G）。
2. グラフ画面の右上の **歯車（グラフの設定）** をクリック。
3. 「**グループ**」を開き、「**新しいグループ**」を押す。
4. 出てきた検索欄に `path:AI秘書/事業` と入力し、右の丸をクリックして **赤** を選ぶ。
5. 同じように「新しいグループ」を押して、次を1行ずつ追加：
   - `path:AI秘書/議事録` → 青
   - `path:AI秘書/会社 OR path:AI秘書/案件 OR path:AI秘書/人物` → 緑
   - `path:AI秘書/文字起こし` → 灰色
   - `path:AI秘書/月別` → 黄
6. 見やすくするには「**フィルター**」の検索欄に `path:AI秘書` と入れる（AI秘書以外を隠す）。
